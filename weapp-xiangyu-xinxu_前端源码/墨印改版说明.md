# 墨印改版说明（设计系统 + 迁移进度）

> 为什么改：原来的「奶油底 + 棕褐色圆角卡片」是模板感最重的组合，看起来像 AI 默认样式。
> 现在换成 **墨印**：纸色底 + 墨黑字 + 朱红一点 + 发丝线，靠排版而不是靠盒子分层。
> 本文档既是设计规范，也是「还有哪些页没改」的进度表。

---

## 一、世界设定（改样式前必须先看）

### 1. 三条铁律

| # | 规则 | 违反后的样子 |
| --- | --- | --- |
| 1 | **不用卡片**。分组靠留白和 `1rpx` 细线 | 又变回"一堆圆角盒子"，一眼模板 |
| 2 | **一屏只有一处朱红**。它是目光落点 | 到处都是红 = 没有重点 |
| 3 | 标题用宋体大字，正文用系统黑体；字号只从阶梯里取 | 临时写死数值，三模式就散架 |

### 2. 色板

| 变量 | 值 | 用途 | 对比度（纸底） |
| --- | --- | --- | --- |
| `--paper` | `#f2efe4` | 页面底色 | — |
| `--paper-2` | `#faf7ee` | 浅一层（按压、占位） | — |
| `--ink` | `#171410` | 主标题、选中态 | 15.9:1 |
| `--ink-2` | `#4b4436` | 正文 | 8.4:1 |
| `--mute` | `#6b6252` | 辅助说明 | 5.2:1 |
| `--rule` | `#cdc5b0` | 发丝线 | — |
| `--rule-2` | `#a89d82` | 加重线、图片边框 | — |
| `--zhu` | `#b3382c` | **唯一的强调色** | 5.2:1 |

> 所有文字都过 WCAG AA（4.5:1）。改颜色前先算对比度，别凭肉眼调。

### 4. 共用件（在 `app.wxss` 里，直接复用）

| 类名 | 长什么样 | 什么时候用 |
| --- | --- | --- |
| `.btn-zhu` | 朱红直角块 + 纸白字 | 一页里**只有一个**主按钮 |
| `.btn-line` | 2rpx 墨框直角块 | 次要但需要成块的动作 |
| `.btn-text` | 文字 + 2rpx 下划（`.zhu` 变红） | 次要动作、返回、清空 |
| `.cap` | 字距拉开的小字 | 区块标签（模板 / 素材 / 五个点位） |
| `.rule` | 1rpx 发丝线 | 代替卡片边框做分组 |

## 三、还欠的账

1. **剩下 8 页没改**：`local-map`、`mine`、`nfc-trace`、`goods-detail`、`my-works`、`my-order`、`setting`、`address`。
   它们的样式还是旧的（`--font-size-*` / `--btn-*` 那套变量，已保留兼容）。现在整站是"三页新 + 八页旧"的状态。
2. **地图底图要手绘**。目前是程序画的彩色示意图 + CSS 墨色化滤镜，能看但撑不住新世界。
   建议尺寸 750×1334，纸色底、墨线画山形与山路、朱点标点位、双线画框。做完把 `pages/index/index.wxss` 里 `.map-shot` 的 `filter` 删掉。
3. **宋体是系统字，不是品牌字**。iPhone 走 Songti SC、Windows 走 SimSun、部分安卓会落到黑体。
   要稳定，得挂思源宋体子集（`wx.loadFontFace` + CDN + 域名白名单，子集可压到 200KB 内）。
4. **彩色图片全部是占位**（`cdn.example.com`），在墨印世界里，占位色块会显得更突兀——插画是下一步的重点，见 `待插画清单.md`。

## 四、怎么继续改下一个页面

1. 打开 `_preview/render.js` 的用法：`node render.js <页面名> [模式] [输出名] [数据文件]`
   它会把真实 WXML/WXSS 按 375×812 渲染成 PNG，**改完先看图再交付**。
2. 照下面顺序重写页面的 `.wxss`：
   - `padding-top` → 24rpx；左右留白用 `--pad-page`
   - 页头：`--f-title` 宋体 + `.cap` 小字 + 一条 `.rule`
   - 列表：条目之间用 `border-bottom: var(--hair) solid var(--rule)`，**不要**包卡片
   - 动作：主按钮 `.btn-zhu`（一页一个），次要 `.btn-text` / `.btn-line`
   - 状态（加载/空/错误）：`.state` 居中宋体一行 + 小字说明；错误用 2rpx 朱红**全框**，不要只描左边
3. 三个模式都要跑一遍截图（`node render.js <page> elder`），确认放大后不串行、不压字。
4. 跑一遍校验（结构 + 对比度 + 交互），全绿再交付。

## 五、为什么不用微信原生 tabBar 图标以外的自定义

原生 tabBar 只能改文字色 / 选中色 / 背景色，图标是 PNG。所以图标必须重新出图，
不能像页面里那样用 CSS 画。要完全控制（比如让选中项是墨底白字），得换成 `custom-tab-bar` 自定义组件，
那样每个 tab 页都要处理选中态同步——这一轮没做，留给下一轮。
