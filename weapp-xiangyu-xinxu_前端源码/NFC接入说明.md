# NTAG215 溯源接入

已配置真实接口：https://jjzb.proxy.lc.cygnomatic.net/api 。utils/api.js 的 USE_MOCK=false 会使整个小程序使用真实后端。

## 先验证页面内读卡

1. 微信开发者工具导入本目录，在微信公众平台配置 request 合法域名 https://jjzb.proxy.lc.cygnomatic.net 。
2. 使用支持页面内 NFC 读卡的真机测试，开启手机 NFC。在 NFC Tools 等写卡工具中，将标签写为 NDEF 文本记录，内容 NFC-TAG-0001，编码 UTF-8。不要锁定标签。
3. 打开小程序 NFC 溯源页面，点击读取按钮并贴近标签，确认出现对应故事。未登记编号不会显示内容。
4. 测试启动路径 pages/nfc-trace/nfc-trace，启动参数 tagId=NFC-TAG-0001，可验证外部入口的内容加载。

页面读取 NDEF 业务编号，不把芯片 UID 当成业务编号。每件实物需独立编号并在 nfc_tags 登记；当前只有四个种子演示编号，未建立正式文创数据。

## 小程序外触碰唤起

普通文本标签只用于页面内读卡，不会自动打开微信小程序。必须先在微信公众平台确认并申请 NFC 标签调起小程序能力，按当前官方后台要求获取对应入口。目标页面为 pages/nfc-trace/nfc-trace，传入每件文创的 tagId。按微信规定的 NDEF 格式写入生成的入口，并对目标 Android / iPhone 真机分别测试。不要将后端 /api/nfc/trace 地址当成小程序唤起入口。

后台资质、设备能力申请、入口生成和实体写卡尚未完成。页面内读卡兼容性与系统外唤起兼容性分别验证，不能以其中一个推断另一个可用。

## 正式内容

nfc_tags 中配置标题、故事、史料图片、普通话/客家话音频、spotId、goodsId。演示史料和音频目前使用占位 URL，需要换成真实资源；MEDIA_BASE_URL 可用于统一替换种子资源前缀。真实史料应由项目方核实，种子故事仅供演示。
