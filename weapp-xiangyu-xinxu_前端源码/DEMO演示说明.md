# 乡语新叙 · 小程序 Demo 演示说明

> 面向：赛事答辩现场操作者
> 版本：可演示完整版（AI 拼贴 / NFC 溯源 / 手绘地图 / 文创商城 / 三种模式）
> 预计时长：**2 分钟精简版** 或 **5 分钟完整版**（见文末计时建议）

---

## 0. 一分钟了解这是什么

一个客家文化主题的微信原生小程序 Demo，围绕「围屋手绘地图」把四个模块串起来：

| 模块 | 一句话 | 关键技术点 |
| --- | --- | --- |
| AI 家庭拼贴 | 拖拽素材做一张客家主题海报 | Canvas 2D 自研拖拽引擎、双指缩放/旋转、导出海报存相册 |
| NFC 溯源 | 碰一碰标签，听一段老故事 | NFC 能力探测与降级、tagId → 故事/点位/商品 |
| 围山手绘地图 | 在插画地图上找「围山小守」小狗点位 | 设计稿坐标按屏幕等比换算、真实经纬度唤起导航 |
| 文创商城 | 用作品图定制文创、模拟下单 | 作品图跨页传递、模拟订单本地落库 |

另有 **三种界面模式**（普通 / 长辈大字 / 儿童简易）贯穿全部页面。

## 1. 演示前准备（3 分钟）

1. **导入项目**
   微信开发者工具 → 导入项目 → 目录选 `weapp-xiangyu-xinxu` → AppID 选「测试号」即可（项目里 `project.config.json` 用的是 `touristappid`）。
2. **关闭域名校验（必须）**
   右上角「详情」→「本地设置」→ 勾选 **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**。
   原因：`mock/` 里的图片与音频统一用的是占位域名 `cdn.example.com`，不关闭会全部加载失败。
3. **建议窗口**
   模拟器选 iPhone X（375×812）或 iPhone 14；**不要用太矮的机型**，画布与地图会按比例缩小。
4. **清一次历史数据（可选但推荐）**
   模拟器菜单「清缓存 → 清除数据缓存」，避免上一场演示留下的作品/订单干扰。

> 现场没有网络也能完整演示：所有数据都来自 `mock/` 本地文件，`USE_MOCK = true` 时不发任何网络请求。只有图片和音频会因为占位域名而走「占位块 / 播放失败提示」，这属于预期行为（见第 6 节 FAQ）。

## 3. 分步操作脚本（含旁白）

### 3.1 首页与底部导航（30 秒）

- 打开小程序，停在**首页**。
- 旁白：*"底部是五个主入口：首页、拼贴、地图、商城、我的。首页只保留了 NFC 溯源——因为碰标签是个动作，不适合单独占一个导航位。"*
- 观察点：标题下方显示「当前模式：普通模式」；底部导航有 5 个图标（首页 / 拼贴 / 地图 / 商城 / 我的），选中项变成棕色。

| 底部 tab | 打开什么 | 备注 |
| --- | --- | --- |
| 首页 | NFC 溯源主入口 | 唯一没进导航的核心模块 |
| 拼贴 | AI 家庭拼贴共创 | 出海报、定制文创 |
| 地图 | 围山手绘地图 | 点小狗看点位 |
| 商城 | 文创商品列表 | 点商品进详情、可模拟下单 |
| 我的 | 我的作品 / 我的订单 / 设置 | 个人中心 |

### 3.2 先切一次模式（重要，建议放前面）

- 底部「我的」→「设置」。
- 依次点 **长辈大字** → 返回：整站字号和按钮明显变大（现场可以让评委看按钮高度）。
- 再进设置切 **儿童简易** → 返回：控件变成大圆角、更圆润。
- 最后切回 **普通模式** 继续演示。
- 旁白：*"三种模式不是换皮，所有页面共用一套 CSS 变量 + 模式类名，切换后字号、按钮尺寸、圆角一起联动。"*

> 设置页的选择会立刻写进本地存储，**下次启动仍然是上次选的模式**。

### 3.3 AI 家庭拼贴（40 秒）

1. 点底部「拼贴」。
2. 点顶部 **童趣拼贴 / 复古拼贴** 切换模板 → 画布会清空、标题同步变化。
3. 点「**一键预置画布内容**」→ 画布上出现 4 个素材（答辩最省时间的展示方式）。
4. 手势演示：
   - 单指拖动素材；
   - 双指捏合缩放；
   - 双指旋转（切到**儿童模式**后旋转会被禁用，只保留缩放——这是需求点）；
   - 点素材右上角红色 **×** 删除。
5. 点中任意素材 → 底部出现素材名与简介，并**自动用普通话朗读**；点「播放客家方言」可切语音（语音跟随设置页的 voiceType）。
6. 点「**生成海报并保存**」→ 相册授权弹窗（同意后提示「已保存到相册」），作品同时进入「我的作品」。
7. 点底部「**定制文创 · 用这张图去挑商品**」→ 跳到商品详情（链路 1 的关键动作）。

### 3.4 商品详情 + 定制预览（30 秒）

- 页面顶部出现「**文创定制预览**」：左边是你的拼贴作品，右边是商品封面。
- 旁白：*"拼贴页把导出的作品图路径通过 URL 参数带到详情页，这里做定制效果预览。"*
- 向下滚动看商品详情图文。

### 3.5 登录 + 收货地址 + 下单（60 秒）

**首次演示必须先把「登录」和「地址」准备好**，否则点购买会被拦下来（会提示去登录 / 去添加地址）。

1. 点底部「**我的**」→ 点「**微信手机号一键登录**」→ 同意授权后显示脱敏手机号（如 `138****8000`）。
   > mock 阶段拿到的是假号；真实手机号必须由后端用 `phoneCode` 换取，前端拿不到明文。
2. 「我的」→「**收货地址**」→「新增收货地址」：填姓名 / 11 位手机号 / 选地区 / 详细地址 → 保存。
   - 也可以点「**使用微信收货地址**」一键导入（会请求 `scope.address` 授权）。
3. 回到商品详情，底部会显示收货地址。
4. 点「**立即购买**」→ 弹出「**下单成功**」：订单号、商品×数量、实付、收货人。
5. 点「查看订单」→ 进入**我的订单**，刚下的那笔排最上面。

> **支付说明（评审一定会问）**：项目是**双模式**。
> `utils/api.js` 里 `PAY_ENABLE = false`（默认）→ 走**模拟支付**，直接判定成功、不扣款；
> 把它改成 `true` 并且 `USE_MOCK = false` 后，才会真正调起 `wx.requestPayment`。
> **个人主体小程序无法使用微信支付**，真实支付需要「企业主体 + 商户号 + 后端统一下单签名」。
>
> **未付款订单怎么办**：如果真实支付时用户取消，订单会保留为「待付款」，
> 在「我的订单」里会显示「**去支付**」按钮，可以再次发起支付。

> **地址说明**：收货地址是**纯本地功能**，存在 storage（键 `MY_ADDRESSES`），不走后端接口。

### 3.6 NFC 溯源（60 秒，重点）

1. 底部「首页」→ 中间那张「碰一碰，听故事」卡片。
2. 页面顶部：如果设备支持 NFC，会出现「触碰 NFC 标签」按钮；不支持则显示原因并**自动隐藏该按钮**，只保留模拟演示与扫码。
3. **模拟 NFC 演示（答辩首选，见第 4 节详解）**：
   - 点示例标签 `NFC-TAG-0001` 的快捷胶囊，或
   - 在输入框里输 `NFC-TAG-0003` 后点「模拟读取」。
4. 结果区出现：故事标题、故事正文、史料图片（点图可看大图），并**自动按当前语音朗读**。
5. 点「**查看地图点位**」→ 跳到手绘地图，并**自动弹出**该点位的小狗弹窗（链路 2）。
6. 返回，点「**购买同款文创**」→ 跳到对应商品详情（链路 3）。

### 3.7 围山手绘地图（40 秒）

1. 点底部「地图」。
2. 旁白：*"底图是手绘插画，点位坐标按设计稿 750×1334 的像素存储，渲染时按屏幕尺寸等比换算，所以换任何手机小狗都不会偏移。"*
3. 点任意一只「围山小守」小狗 → 底部弹窗出现：点位名称、简介、配图、经纬度。
4. 点「**导航到这里**」→ 唤起微信内置地图并定位到真实经纬度。
5. 若从 NFC 页带 `spotId` 进来，弹窗会**自动打开**，无需再点。

### 3.8 我的作品 / 我的订单（15 秒，可选）

- 我的作品：展示刚才生成的海报，点击看大图，**长按可删除**。
- 我的订单：本地模拟订单 + mock 历史订单合并，按下单时间倒序。

## 4. 模拟 NFC 专项说明（答辩必看）

### 4.1 为什么需要「模拟」

微信小程序对第三方开放的 NFC 读卡能力有限：`wx.startNFC` 只在部分基础库 / 机型存在，HCE 相关接口也不是全设备支持。
本项目对 NFC 做了**能力探测 + 三级降级**：

1. 有 `wx.startNFC` → 用它启动读卡；
2. 没有则尝试 `wx.getHCEState` / `wx.startHCE` 降级；
3. 两者都不可用 → 判定「设备不支持」，**隐藏触碰按钮**，显示原因，只保留模拟演示与扫码。

所以现场**不依赖真机 NFC**，用模拟入口即可完整演示溯源链路。

### 4.2 三种触发方式

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| **快捷胶囊（最快）** | 直接点 `NFC-TAG-0001` ~ `0004` 任一胶囊 | 一行代码都不用输，答辩首选 |
| **手动输入** | 输入框输入 tagId → 点「模拟读取」 | 可演示「未知标签」的错误处理，如输 `NFC-TAG-9999` |
| **扫码** | 点「扫码读取标签」 | 扫任意内容含 `tagId=xxx` 的二维码，或直接扫码得到 `NFC-TAG-0002` |

> 扫码支持三种内容格式：纯 tagId、`?tagId=xxx` 的 URL、`xiangyu://nfc/NFC-TAG-0001` 自定义 scheme。

### 4.3 四个标签的演示对照表

| tagId | 故事 | 关联点位（跳地图） | 关联商品（跳商城） |
| --- | --- | --- | --- |
| `NFC-TAG-0001` | 围屋门楼 | spot-01 客家围屋 | goods-01 客家围屋冰箱贴 ¥39 |
| `NFC-TAG-0002` | 土楼天井 | spot-02 圆形土楼 | goods-04 土楼手绘帆布袋 ¥69 |
| `NFC-TAG-0003` | 擂茶老铺 | spot-03 擂茶老铺 | goods-03 擂茶礼盒 ¥128 |
| `NFC-TAG-0004` | 花灯作坊 | spot-04 花灯工坊 | goods-05 客家花灯书签 ¥19 |

### 4.4 推荐的 30 秒话术

> "真机 NFC 受微信开放能力限制，不一定每台手机都可用，所以产品上做成了三层：能读就真读、读不了自动隐藏按钮、同时保留模拟与扫码两条演示通路。现在我用模拟标签演示——"
> （点 `NFC-TAG-0003`）"——碰一下，故事、史料图和双语音频都出来了；点这里直接跳到这张标签所在的地图点位，也可以去买同款文创。"

## 6. 常见问题与现场应对（FAQ）

| 现象 | 原因 | 应对 |
| --- | --- | --- |
| 商品封面、素材图显示成**色块/文字** | mock 里是占位域名 `cdn.example.com`，无真实图片 | 正常现象，说明「图片加载失败已有兜底」。想看到真图：把 `mock/*.js` 里的 `imageUrl` / `coverUrl` 换成真实 CDN 并配好域名 |
| 点素材播放音频，提示「播放失败（占位地址）」 | 同上，音频也是占位地址 | 正常兜底；换真实音频 URL 即可 |
| 保存海报提示「作品已存，相册未授权」 | 拒绝了相册权限 | 弹窗点「去设置」开启；作品本身已保存进「我的作品」 |
| NFC 页没有「触碰 NFC 标签」按钮 | 当前设备/基础库不支持 NFC | **预期行为**，用模拟演示或扫码；页面会显示具体原因 |
| 商品详情看不到「文创定制预览」 | 不是从拼贴页「定制文创」进来的 | 只能从拼贴页底部按钮进入才带作品图；从列表进是普通详情 |
| 连续点很多次后提示跳转失败 | 页面栈上限 10 层 | 已做降级：失败自动 `redirectTo`，不会卡死 |
| 地图小狗位置看着不对 | 底图被替换但坐标不是 750×1334 设计稿 | 必须同时改 `pages/local-map/local-map.js` 的 `MAP_DESIGN` 与底图尺寸 |
| 清缓存后作品/订单没了 | 作品与模拟订单存在本地 storage | 预期行为，重新生成/下单即可 |

## 7. 技术要点速查（评委提问用）

- **纯原生**：微信原生小程序，**未使用 uni-app / 任何第三方 UI 框架**，零 npm 依赖。
- **接口层解耦**：`api/` 定义接口，`mock/` 放模拟数据，`utils/api.js` 顶部一个 `USE_MOCK` 开关 + `BASE_URL`，切到真实后端只改这一处。
- **坐标换算**：`utils/map-calc.js` 做设计稿像素 ↔ 屏幕渲染坐标换算，点位在任意屏幕都对齐（有单测覆盖）。
- **自研画布**：`components/drag-canvas/` 基于 Canvas 2D，自己实现命中检测、拖拽、双指缩放/旋转、导出海报。
- **模式系统**：`app.wxss` 定义三套 CSS 变量，页面根节点挂 `ui-mode-elder` / `ui-mode-child` 类名，全站联动。
- **容错**：所有图片 `binderror` 兜底、音频 `onError` 兜底、接口失败有 toast/空态、跳转失败降级重定向。
- **双模式支付**：`utils/api.js` 的 `PAY_ENABLE` 默认 `false` → 模拟支付，不调微信支付；改成 `true` 且关掉 mock 后才真正调 `wx.requestPayment`。个人主体小程序无法使用微信支付。
- **手机号登录**：`<button open-type="getPhoneNumber">` 拿 code → 后端换手机号，**前端拿不到明文手机号**。
- **收货地址**：纯本地 storage（`MY_ADDRESSES`），不走后端。
