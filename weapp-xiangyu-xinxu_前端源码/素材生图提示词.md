# 8 个拼贴素材的生图提示词

> 用途：把现在的矢量插画换成照片。
> 做法：把每条提示词粘到生图工具 → 出图 → 存成对应文件名 → 覆盖 `assets/images/materials/` 里的同名文件 → 开发者工具重新编译。
> **不用改任何代码**（文件名和路径已经接好了）。

## 通用参数

| 项 | 建议 |
| --- | --- |
| 比例 | **1:1 正方形**（素材在画布上是方的，长图会变形） |
| 尺寸 | 512×512 或 1024×1024 |
| 格式 | **PNG**（和现在同名，直接覆盖） |
| 统一风格后缀 | `，真实照片，自然光，浅景深，低饱和暖调，无文字无水印` |

把统一后缀加在每条提示词末尾，8 张的调性才一致。

## 替换步骤（3 步）

1. 生成 8 张图，分别命名为：
   `mat-childlike-01.png` ~ `mat-childlike-04.png`、`mat-retro-01.png` ~ `mat-retro-04.png`
2. 覆盖到 `assets/images/materials/` 目录（同名直接替换）
3. 微信开发者工具按 `Ctrl+B` 重新编译

**注意**：图片必须裁成**正方形**。长方形会被 `aspectFit` 缩进方框里，左右留白，看起来像没裁好。

## 两个提醒

**1. 版权**
AI 生成图能不能商用，取决于平台条款；答辩/教学用途基本没问题。如果要正式上线卖文创，建议换成自己拍的照片或者买授权图。

**2. 照片和插画拼在一起会打架**
现在整套 UI 是"纸 + 墨 + 插画"的语言。如果 8 张全换成照片，拼贴出来的海报会变成"照片贴纸"风——**这其实更接近真实产品**（家庭相册 + 装饰素材），但和首页那种排版风格会有落差。如果要换，建议**整套一起换**，别只换一半。

另一种更稳的配法：**照片当"主图素材"，插画留作"装饰素材"**（比如花灯、绣花鞋继续用插画，围屋、土楼换成照片），两种材质混着贴反而更像手账。
